# Raw inputs

`Digital Trade Indicators Measurements.xlsx` (the raw DTI dataset) is included in this folder. The other files must be placed here before running the pipeline; they are excluded from version control because of size and/or the providers' redistribution terms.

| File | Source | Used by |
|---|---|---|
| `Digital Trade Indicators Measurements.xlsx` **(included)** | Digital Trade Integration (DTI) database, Ferracane & van der Marel (ECIPE / EUI), raw regulatory measures export | `DTI_BPM6_Mapping_Final_Pipeline.ipynb` |
| `data_result.csv` | UN Comtrade v1 API, services (EBOPS as reported), annual imports, 2000-2025. Generated by `dataset_creation.ipynb` (requires a free Comtrade subscription key) | `dti_comtrade_final_merge.ipynb` |
| `Gravity_csv_V202211/Gravity_V202211.csv` | CEPII Gravity database, release V202211 (Conte, Cotterlaz & Mayer 2022): https://www.cepii.fr/CEPII/en/bdd_modele/bdd_modele_item.asp?id=8 | `cepii_preprocess_notebook.ipynb` |

World Bank WDI series (GDP, population) are downloaded at run time through the R `WDI` package; no file is needed.
